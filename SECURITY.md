# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Contact the repository owner privately through the email address listed on the GitHub profile and include steps to reproduce the issue, its impact, and any suggested mitigation.

Do not include passwords, access tokens, private job postings, or other sensitive data in reports.

## Privacy

Job-posting text may contain personal or confidential information. Do not commit real user submissions, credentials, API keys, or downloaded datasets to this repository.
