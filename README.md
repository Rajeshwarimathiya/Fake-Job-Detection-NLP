# fake-job-detection
AI-powered fake job posting detection system built with Python, Streamlit, machine learning, NLP, XGBoost, scikit-learn, and SHAP explainability.

## Project links

- Author: Rajeshwari Mathiya
- [LinkedIn](https://www.linkedin.com/in/rajeshwari-mathiya-77a4a3321)
- [GitHub profile](https://github.com/Rajeshwarimathiya)

## Repository contents

The application analyzes job titles, descriptions, and requirements, then provides a prediction, confidence score, review signals, batch CSV analysis, and SHAP explanations.

Training data is intentionally excluded from Git. Keep it in `data/fake_job_postings.csv` locally.

See [CONTRIBUTING.md](CONTRIBUTING.md) for development guidance and [SECURITY.md](SECURITY.md) for responsible vulnerability reporting.
